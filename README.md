# Arturito y el Halcón Milenario

Aplicación web interactiva que recrea digitalmente la actividad **Arturito y el Halcón Milenario**.

## Descripción

La actividad original consiste en trazar sobre un papel el recorrido que realiza Arturito a través de un laberinto hasta llegar al Halcón Milenario. En este proyecto, el papel se reemplaza por la computadora: Arturito se representa como un círculo que puede desplazarse por el laberinto y el recorrido puede observarse directamente en pantalla.

La aplicación también incluye una visualización del recorrido solución de la actividad 1 (bajar por la tuberia A) para comparar el camino realizado con el algoritmo de la actividad.

## Controles

- **Flechas del teclado:** mover a Arturito hacia arriba, abajo, izquierda o derecha.
- **Teclas A, B, C, D y E:** ubicar a Arturito en la entrada del tubo correspondiente.
- **Enter:** reiniciar la actividad y borrar el recorrido dibujado.
- **R:** mostrar el recorrido de solución.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- [p5.js](https://p5js.org/)

## Cómo ejecutar el proyecto

1. Descargar o clonar este repositorio.
2. Abrir el archivo `index.html` en un navegador web.

La librería p5.js se carga desde un CDN, por lo que se necesita conexión a Internet al abrir la aplicación.
